Microsoft Reminds Customers Windows 11 23H2 Enterprise and Education Lose Updates in November

The November 2026 security update will be the last for the 23H2 Enterprise, Education and IoT Enterprise editions; Microsoft points users to version 26H2.

By TNC NewsdeskOctober 12, 2026 · 2 min read
MicrosoftCloud & Infrastructure

Microsoft has told customers that Windows 11, version 23H2 will reach end of support next month for its Enterprise, Education and IoT Enterprise editions, BleepingComputer reported on October 12. The November 2026 Windows security update will be the final one those editions receive.

What Microsoft said

In a message center update, Microsoft said affected devices will stop getting monthly security updates after that date and recommended moving eligible machines to a supported Windows 11 release. The Home and Pro editions of 23H2 already reached end of support in November 2025.

The recommended target is Windows 11, version 26H2, also called the Windows 11 2026 Update. It became generally available in September 2026 as an enablement package, is rolling out in phases, and installs with a single restart. Consumer support for 26H2 runs to October 2029.

Steps for administrators

  • Identify devices running 23H2 Enterprise, Education or IoT Enterprise.
  • Check whether they are eligible for 26H2.
  • Turn on "Get the latest updates as soon as they're available" to receive the update sooner, or go to Settings > Windows Update and select "Check for updates."
  • Plan replacements or other upgrade paths for devices that are not eligible before November.

Other lifecycle dates

BleepingComputer's report also lists related timelines:

  • Windows 11 24H2 Home and Pro stop receiving updates in October 2026, while 24H2 Enterprise and Education stay under mainstream support until October 2027.
  • Free Extended Security Updates for Windows 10 home users have been extended to October 2027.
  • Windows Server 2022 reaches the end of mainstream support, with extended support until October 14, 2031.

Devices that remain on unsupported Windows versions will also stop receiving security updates after next year's Windows Update certificate rotation, the report says. Microsoft's Windows Lifecycle FAQ lists servicing dates for each release.
