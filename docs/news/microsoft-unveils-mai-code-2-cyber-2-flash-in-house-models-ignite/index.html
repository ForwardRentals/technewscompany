Microsoft Unveils MAI Code 2, Cyber 2 Flash and Other In-House AI Models at Ignite

Microsoft's AI unit says its new coding model approaches rival performance at a lower price; the benchmark comparisons are the company's own.

By TNC NewsdeskNovember 17, 2026 · 2 min read

Photo: Christopher Wilson / CC BY-SA 4.0 via Wikimedia Commons

Microsoft introduced a new set of in-house AI models on November 17 at its Ignite conference, led by a coding model called MAI Code 2, according to Axios. Axios counted six models; some other outlets counted seven, depending on how the transcription model is grouped.

What was announced

Microsoft's performance and price claims, as reported by Axios and other outlets, include:

  • MAI Code 2: Microsoft says it delivers 98% of the performance of OpenAI's GPT-6.1 Sol at 40% of the price, and 96% of Claude Opus 5.5's performance at 5% of the cost.
  • MAI Code 2 Flash: A smaller, faster variant, which Microsoft says matches GPT-6 Luna at 65% of the price.
  • MAI Cyber 2 Flash: A security model that Microsoft says beats GPT-6 Astra on a security benchmark at under 2% of the cost per task. It is initially limited to a small group of customers.
  • MAI Image 2.7: Microsoft says it ranks first in image editing.
  • Voice and transcription: MAI Realtime 1 for live voice conversations and Dragon Copilot Transcribe.

MAI Code 2 and Code 2 Flash are available in GitHub Copilot and Microsoft Foundry.

Caveats

Axios noted that the comparisons rest on selected benchmarks and that some pricing reflects promotional discounts. All figures are Microsoft's and have not been independently verified.

Licensing and strategy

Enterprises can customize the models with proprietary data but must deploy them within Azure. Microsoft AI CEO Mustafa Suleyman said the approach would "feel like open source" while offering more security and control, per Axios. He declined to give a target for how much Copilot traffic will move to Microsoft's own models.

Suleyman also said, "My team is building true superintelligence," and said progress on a larger general-purpose model is strong, without giving a release date.

Context

The launch follows Microsoft's earlier MAI releases in June and reflects its effort to build models of its own alongside those from its partners. Axios reported that OpenAI also released new models the same day.
