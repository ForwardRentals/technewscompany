Microsoft Unveils Surface Laptop Ultra and RTX Spark AI PCs at First Windows Event in Two Years

Satya Nadella and Jensen Huang shared the stage as Microsoft bet on laptops that run large AI models locally.

By TNC NewsdeskOctober 7, 2026 · 2 min read

Photo: Brian Smale and Microsoft / CC BY-SA 4.0 via Wikimedia Commons

Microsoft held its first dedicated Windows and Surface event in more than two years on Tuesday, introducing a new class of Windows PCs built around Nvidia's RTX Spark chip and designed to run advanced AI models on the device.

Microsoft CEO Satya Nadella was joined on stage by Nvidia CEO Jensen Huang and Windows + Devices chief Pavan Davuluri.

Surface Laptop Ultra

The headline product, first teased at Computex 2026, is the Surface Laptop Ultra. Microsoft says it offers:

  • Up to 128GB of unified memory and up to 1 petaflop of FP4 AI performance
  • A 15-inch PixelSense Ultra touchscreen
  • 2.5x the thermal capacity of other Surface Laptops, keeping 99% of its performance on battery
  • A chassis under 18mm thick and under 4.5 pounds

Pricing starts at $2,599.99 for the 5,120-core GPU / 18-core CPU model and $3,699.99 for the 6,144-core GPU / 20-core CPU model, in Platinum and Nightfall. Preorders opened during the event.

Dev Box and partner laptops

Microsoft also opened preorders for the Surface RTX Spark Dev Box at $5,999. RTX Spark laptops from Lenovo, Asus, Dell, MSI and HP, including the Dell XPS 16 and HP OmniBook Ultra 16, went up for preorder with shipping set for October 16. Two DGX Station desktops for Windows are due later this year.

Copilot gets local

On the software side, Copilot gains a new homepage, permission-based access to local files, the ability to build native Windows apps from a prompt, and a "Hybrid Intelligence" mode that picks between local and cloud models. Microsoft said those features roll out over the next couple of months. A redesigned Windows Search with more than 1,000 quick actions is coming this fall.

Notably absent: Windows 12. All of the updates shipped as part of Windows 11.
